# Essay and comprehension reading tests for competitive exams

Thirty essay-based reading comprehension tests (each an essay of roughly 600 to 900 words with ten questions) for practice towards SSC, CDS, CAT, UPSC, CTET and similar examinations.

* `source/original/` holds the files exactly as they were supplied (test-01.json to test-30.json, the topic list with the generation prompt, and the Reading Studio specification). They are not edited.
* The files do not share one layout (different key names for the questions, answers given as letters, as "B) text", or as full sentences, essays given as text or as objects). A normalising script and an audit report are added in later commits.
